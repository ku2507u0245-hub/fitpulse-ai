# 💪 FitPulse AI

### AI-Powered Campus Fitness & Gamification Platform

FitPulse AI is an AI-powered campus fitness platform designed to encourage students and faculty to stay active through **computer vision, gamification, rewards, and personalized fitness guidance**.

The platform uses camera-based motion tracking to analyze exercises, count valid repetitions, provide real-time motivation, and reward users with **FitCoins** that can be redeemed for campus benefits.

---

## 🚀 Key Features

- 🎥 **AI Motion Tracking**
  - Real-time exercise tracking using computer vision
  - Body pose and movement analysis

- 🤖 **Exercise Form Analysis**
  - Tracks body landmarks
  - Calculates joint angles
  - Provides form feedback

- 🔢 **Automatic Rep Counting**
  - Detects valid exercise repetitions
  - Supports exercises such as squats and bicep curls

- 🪙 **FitCoins Reward System**
  - Earn FitCoins by completing valid repetitions
  - Earn XP and level up through consistent activity

- 🎁 **Campus Rewards**
  - Redeem FitCoins for campus benefits such as:
    - Canteen discounts
    - Stationery vouchers
    - Sports facilities
    - Campus event benefits
    - Achievement badges

- 🏆 **Achievements & Levels**
  - Track fitness progress
  - Unlock achievements
  - Build consistency through gamification

- 🥗 **Fitness Plan**
  - Simple student-friendly fitness and nutrition guidance

- 🔊 **AI Motivation**
  - Real-time motivational feedback during workouts
  - Voice-based encouragement while exercising
